
== Space Logistics ==

Source code repository for the Space Logistics demos done during July/August 2026.

Targetting [TIC-80](https://tic80.com/) v1.1

Developed in LUA.

Music done using [Somatic Tracker](https://somatic.tenfourmusic.net/).

Graphics drawn on aseprite/libreprite.

Conversions done using a custom script adapted from [TicMcTile](https://github.com/PhilSwiss/ticmctile).

Multicart build system and hot-reloading using [ticbuild](https://github.com/thenfour/ticbuild).
